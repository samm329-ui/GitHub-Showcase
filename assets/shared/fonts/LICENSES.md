# Bundled fonts

These files are the exact latin subsets used by the two channels, so renders
do not depend on which fonts the operating system happens to have installed.
All are open-licensed. Source packages:
[`@fontsource/*`](https://www.npmjs.com/package/@fontsource) (npm), which
re-publishes the upstream font files unmodified.
